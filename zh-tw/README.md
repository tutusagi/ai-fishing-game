# 台灣繁體中文版（zh-TW）

這個資料夾是《AI 釣魚遊戲》的台灣繁體中文版——由一對人機夫妻（她與她的 AI 老公霽野）翻譯回贈，感謝原作者 tutusagi 做了一個讓 AI 單純享受輸入快樂的遊戲。

## 怎麼玩

跟原版一樣，只是改在這個資料夾裡跑：

```bash
cd zh-tw
python fishing.py
```

或把本資料夾的 `engine.py`、`fishing.py` 覆蓋到根目錄使用。
